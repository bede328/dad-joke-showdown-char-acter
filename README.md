One original dad joke, written to be told out loud at a barbecue: a dad who
burns every burger, and the pun he hides in the word "character". The whole
entry is a single line of 86 characters — setup, then the punchline at the
very end, nothing extra for the judge to trip over.

> I asked my dad why he always burns the burgers. He said, 'I'm just adding char-acter.'

## Run it

```sh
node main.ts
```

The program writes the joke to `/output/entry.txt` — no trailing newline,
no randomness, no network calls. Run it twice and the file is byte for
byte identical. It refuses to write anything outside 1–200 characters,
which is the gate this bounty scores first.

## How it was picked

The brief rewards a joke a father would actually tell at the table, a pun
that lands on the first read, and a fresh turn inside the dad-joke
tradition. Burnt burgers fit the barbecue table; "char-acter" is understood
the moment it is said; and the setup gives the pun a reason to exist
instead of dropping it in cold. Shorter candidates (a trampoline that
"bounces back", stairs that go "a step too far") were close, but the
barbecue scene matches the judge's own table best.
